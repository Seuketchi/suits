# Guides

One page per kind of user: who it is for, the jobs they bring, who takes each one and what to type, what comes back, and a short worked example. Every command shown ships in this plugin. Not sure who to ask? Ask donna: `/suits:donna <your request>`.

- **[Researcher](./researcher.md)**: sources, outside facts and the behaviour of your own analysis code, then the write-up.
- **[Startup founder](./startup-founder.md)**: whether to build, the plan, the pitch and the money check.
- **[Developer](./developer.md)**: read the code, build test first, chase a bug to its cause, review and write the pull request.
- **[Project manager](./project-manager.md)**: tickets, status, readiness for a release, minutes and a retro.
- **[Solo freelancer or consultant](./freelancer-consultant.md)**: proposals, emails, negotiation, client status and follow-ups.
- **[Student writing a thesis](./thesis-student.md)**: sources, checked facts, a writing plan and the defense.
