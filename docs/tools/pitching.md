## What it does

`pitching` structures, writes and reviews a startup or product pitch for competitions, investors, school administrators or mixed audiences. It sets the order of the story, the limits on each slide, and what to cut for the audience in the room.

## When to reach for it

When someone asks to pitch, outline a pitch, prepare a demo day presentation, or review a pitch's structure. Harvey uses it to set the structure; donna builds the deck from it.

## Common questions

**Does it build the slides?**
No. It sets the structure and the content rules. The deck is built separately.

**Does it use a company's own material?**
Only what the request supplies. It holds no company reference documents.

## It's working if

- The structure fits the audience named in the request.
- Each slide carries one point and stays within the word limit.
- The most important content sits at the top of the slide.
- A live demo replaces video.
