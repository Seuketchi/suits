# Tools

The skills the characters call. Each is a separate file, never copied into a character, so improving a tool improves every character that uses it. Characters live in [characters](../characters/README.md).

## User-invoked

- **[retro](./retro/SKILL.md)**: Look back at a batch that has landed and propose fixes to the owner's setup, from the logs and the review rounds. Started by the owner; offered by jessica.

## Model-invoked

- **[code-review](./code-review/SKILL.md)**: Review the changes since a fixed point on two axes: repo standards and spec. Called by louis.
- **[codebase-design](./codebase-design/SKILL.md)**: Shared vocabulary for designing deep modules: interface, seam, depth. Called by harvey.
- **[critical-path](./critical-path/SKILL.md)**: Work out the longest chain of blocked tickets and each ticket's float, from the blocker edges. Called by jessica.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)**: Diagnosis loop for hard bugs and performance regressions. Called by associates.
- **[domain-modeling](./domain-modeling/SKILL.md)**: Build and sharpen a project's domain model: CONTEXT.md and ADRs. Called by mike.
- **[findings](./findings/SKILL.md)**: The one format every investigation writes to. Called by mike, rachel.
- **[go-live-check](./go-live-check/SKILL.md)**: Build the go-live check for a release: at most 30 lines, each with its reason, check and evidence. Called by jessica.
- **[grilling](./grilling/SKILL.md)**: Question the user about a plan, decision, or idea until every open decision is settled. Called by harvey.
- **[handoff](./handoff/SKILL.md)**: Write the session up as a short document so another session can pick the work up. Called by donna.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)**: Scan a codebase for deepening opportunities, present them as a visual report, then grill through the one you pick. Called by harvey.
- **[money-check](./money-check/SKILL.md)**: A ten-item check on amounts, fees, limits, rates, rounding, currency and balances in a diff or spec. Called by louis.
- **[morning-brief](./morning-brief/SKILL.md)**: A private daily brief of what is assigned and what needs review, with pending reviews only the owner can see. Called by donna.
- **[negotiation-prep](./negotiation-prep/SKILL.md)**: Prepare a negotiation as five rows: interests, alternatives, walk-away point and authority. Called by harvey.
- **[pitching](./pitching/SKILL.md)**: Structure, write and review a pitch for the audience in the room. Called by harvey.
- **[pr](./pr/SKILL.md)**: Write a pull request body: a summary view, evidence, and how hard it is to undo. Called by donna.
- **[prototype](./prototype/SKILL.md)**: Build a throwaway prototype to answer a design question. Called by associates.
- **[raid-log](./raid-log/SKILL.md)**: Keep the risk log of risks, assumptions, issues and dependencies in one row shape. Called by jessica.
- **[recall](./recall/SKILL.md)**: Search past sessions for how something was done or decided. Called by mike.
- **[research](./research/SKILL.md)**: Answer an outside question from primary sources, as a cited findings file. Called by rachel.
- **[reverse-engineer-anything](./reverse-engineer-anything/SKILL.md)**: Work out what a shipped artifact does when there is no source (from morluto/rea). Called by mike.
- **[root-cause-audit](./root-cause-audit/SKILL.md)**: Frame the causes of a bug in three directions: deeper, sideways, back up. Read only. Called by rachel.
- **[scrum](./scrum/SKILL.md)**: Draft a daily standup report from real git and GitHub activity. Called by donna, jessica.
- **[senior](./senior/SKILL.md)**: A senior developer's judgement before a non-trivial change, and a read-only PR review. Called by harvey.
- **[slides](./slides/SKILL.md)**: Build a slide deck as a PDF from a set pitch structure: one point a slide, notes in the source, the same checks as a document. Called by donna.
- **[source-finder](./source-finder/SKILL.md)**: Find and verify real academic papers for a claim, a topic, or a gap. Called by rachel.
- **[status-report](./status-report/SKILL.md)**: Write the one-page status report, state first, with a decision line. Called by jessica.
- **[stocktake](./stocktake/SKILL.md)**: Audit how our own code behaves today, citing file:line for every claim. Called by mike.
- **[tdd](./tdd/SKILL.md)**: Test-driven development: red, green, refactor. Called by associates.
- **[test-kitchen](./test-kitchen/SKILL.md)**: Settle a question by measuring it on staging and record the data. Called by mike.
- **[to-spec](./to-spec/SKILL.md)**: Turn the conversation into a spec; publish to the tracker only when asked. Called by jessica.
- **[to-tickets](./to-tickets/SKILL.md)**: Break a plan or spec into tracer-bullet tickets with blocking edges. Called by jessica.
