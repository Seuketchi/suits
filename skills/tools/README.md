# Tools

The skills the characters call. Each is a separate file, never copied into a character, so improving a tool improves every character that uses it. Characters live in [characters](../characters/README.md).

## User-invoked

None yet.

## Model-invoked

- **[code-review](./code-review/SKILL.md)**: Review the changes since a fixed point on two axes: repo standards and spec.
- **[codebase-design](./codebase-design/SKILL.md)**: Shared vocabulary for designing deep modules: interface, seam, depth.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)**: Diagnosis loop for hard bugs and performance regressions.
- **[domain-modeling](./domain-modeling/SKILL.md)**: Build and sharpen a project's domain model: CONTEXT.md and ADRs.
- **[findings](./findings/SKILL.md)**: The one format every investigation writes to.
- **[grilling](./grilling/SKILL.md)**: Question the user about a plan, decision, or idea until every open decision is settled.
- **[handoff](./handoff/SKILL.md)**: Write the session up as a short document so another session can pick the work up.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)**: Scan a codebase for deepening opportunities, present them as a visual report, then grill through the one you pick.
- **[morning-brief](./morning-brief/SKILL.md)**: A private daily brief of what is assigned and what needs review, with pending reviews only the owner can see.
- **[pitching](./pitching/SKILL.md)**: Structure, write and review a pitch for the audience in the room.
- **[pr](./pr/SKILL.md)**: Write a pull request body: a summary view, evidence, and how hard it is to undo.
- **[prototype](./prototype/SKILL.md)**: Build a throwaway prototype to answer a design question.
- **[recall](./recall/SKILL.md)**: Search past sessions for how something was done or decided.
- **[research](./research/SKILL.md)**: Answer an outside question from primary sources, as a cited findings file.
- **[reverse-engineer-anything](./reverse-engineer-anything/SKILL.md)**: Work out what a shipped artifact does when there is no source (from morluto/rea).
- **[scrum](./scrum/SKILL.md)**: Draft a daily standup report from real git and GitHub activity.
- **[senior](./senior/SKILL.md)**: A senior developer's judgement before a non-trivial change, and a read-only PR review.
- **[source-finder](./source-finder/SKILL.md)**: Find and verify real academic papers for a claim, a topic, or a gap.
- **[stocktake](./stocktake/SKILL.md)**: Audit how our own code behaves today, citing file:line for every claim.
- **[tdd](./tdd/SKILL.md)**: Test-driven development: red, green, refactor.
- **[test-kitchen](./test-kitchen/SKILL.md)**: Settle a question by measuring it on staging and record the data.
- **[to-spec](./to-spec/SKILL.md)**: Turn the conversation into a spec; publish to the tracker only when asked.
- **[to-tickets](./to-tickets/SKILL.md)**: Break a plan or spec into tracer-bullet tickets with blocking edges.
